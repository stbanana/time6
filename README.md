# time6 · 28 小时时钟

一天 28 小时，一周 6 天。页面只做一件事：**用 28 小时制显示现在几点**，并告诉你距离每天的推荐入睡时间还有多久。

**线上地址：<https://stbanana.github.io/time6/>**

---

## 它显示什么

- **28 小时制时间**：`00:00 – 27:59`，只到分钟，不显示秒
- **星期**：周一 – 周六（28h 世界的一周只有 6 天）
- **推荐入睡**：每天 `20:00`（28 小时制）
- **倒计时**：`距推荐入睡 2 小时 13 分`，过了入睡点则显示 `已过推荐入睡 …`

没有阶段、没有睡眠时长、没有一周 6 轮表；不推算睡眠，也不显示真实世界的日期和秒。

---

## 换算规则

- 1 天 = 28 小时；1 周 = 6 天 = 168 小时
- 锚点：**2026-01-05（周一）00:00（设备本地时区）**＝ 28h 世界的 周一 00:00
- 当前是第几天：`floor(自锚点起的小时数 mod 168 / 28)` → 周一 … 周六
- 当前 28h 时刻：`自当天 00:00 起的小时和分钟` → `00:00 – 27:59`
- 推荐入睡固定为每天的 `20:00`；页面计算距离它还有多久，或已经过去多久

所有计算只用绝对毫秒时间戳和取模，跨天、跨周不会出现负值或跳变；显示按访问者设备时区。

### 改配置

编辑 [`assets/js/schedule.js`](./assets/js/schedule.js) 顶部：

```js
var BEDTIME_HOUR = 20;                                  // 推荐入睡（28h 制）
var ANCHOR = new Date(2026, 0, 5, 0, 0, 0, 0);          // 28h 周一 00:00 对应的真实时刻
```

只改这两个常量，钟面、星期、倒计时都会一起重算。

## 本地预览

1. 直接双击 `index.html`（不使用 `type="module"`，`file://` 可用）
2. 或起一个静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## 自测

```bash
node tests/schedule.test.js
```

覆盖锚点、跨天/跨周、20:00 入睡边界、随机时刻的 28h 时间与倒计时不变量，并断言界面文案不含「秒」。

```bash
node tests/browser-check.js
```

用本机 Edge 无头模式检查 320 / 390 / 768 / 1024 / 1440 五档布局、Console 报错、表盘刻度、主题切换，并模拟「已过推荐入睡」；截图与报告写入 `.preview/`。

## 部署

仓库 `main` 分支根目录直接发布到 GitHub Pages：

1. Settings → Pages → Source: **Deploy from a branch**
2. Branch: `main`，Folder: `/ (root)`
3. push 后 1–10 分钟生效

资源全部使用相对路径，项目页挂在 `/<repo>/` 子路径下也能正常加载。

## 浏览器支持

现代浏览器（Chrome / Edge / Safari / Firefox 最近两年版本）。`backdrop-filter`、`svh` 等特性在旧浏览器上会优雅降级，核心时间计算不受影响。
